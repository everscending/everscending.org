## 5. Key insights and learnings

1. **Host-derived API base worked:** Dropping `VITE_BLOG_API_BASE` in favor of `getBlogApiBaseUrl()` from `window.location.host` simplified config and matched architecture; README documents full host mapping.
2. **React Query fit well:** useQuery gave loading/error/success and non-blocking behavior without custom state; QueryClientProvider in main.tsx and module-boundary mocks in tests kept integration clean.
3. **Slug sanitization is non-optional for links:** Building `/blog/${slug}` without validation could allow unsafe values once Epic 3 adds the route; sanitizing in the mapper (e.g. `safeSlugForLink()`) is the right place.
4. **Error UX when refetch fails:** Showing both cached list and error message was confusing; rendering error-only when `isError` improved clarity.
5. **File list and branch scope:** Including “branch contains 2.1 + 2.2” in 2.2’s Dev Agent Record improved traceability; consider standardizing branch-scope notes when multiple stories ship together.
